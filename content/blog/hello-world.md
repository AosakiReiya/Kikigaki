開博客這種事，我其實猶豫了很久。總覺得自己寫得不好、內容不夠深，發出去會被人笑。

後來想通了：**不是寫給別人看的，是寫給自己看的。**

## 為什麼要有這個博客

一直以來，我有個很壞的習慣 — 學新東西就裝進書籤資料夾，然後再也沒碰過。看過的教學、踩過的坑、解決問題瞬間的靈感，全都散在不同地方，回過頭什麼也找不到。

寫下來就不一樣了：

- 想解釋一件事，就得真的搞懂它，裝懂馬上會被發現
- 踩過的坑留個紀錄，下次遇到直接翻自己的筆記
- 偶爾有人路過留言，聊兩句還挺開心的

所以這個博客誕生了。內容大概會圍繞我平常在碰的東西：

1. **前端開發** — SvelteKit、Web 動畫、效能優化
2. **網頁設計** — 轉場、互動細節、視覺實驗
3. **佈局與部署** — Cloudflare Pages、D1、R2 這套接近免費的方案

第一篇就寫到這，篇幅太長反而沒人看。接下來我會從這個網站本身拆起 — **它上面的轉場動畫、資料架構、部署方式，都是現成的教材**。

如果你看到什麼想討論的，歡迎在文章底下留言，我不保證秒回，但我會看。

## 附錄：這板博客用的 Markdown 語法

既然開場白太短，順便附上這個博客支援的 Markdown 語法，你之後寫作（或寫給我看）都用得上。

**標題** — 用 `#` 到 `######`，對應六級標題。文章內的 `##` / `###` 會自動收集成右上角的目錄：

```markdown
## 這是二級標題

### 這是三級標題
```

**強調與刪除線：**

- _斜體_：兩邊各一個 `*`
- **粗體**：兩邊各兩個 `*`
- ~~刪除線~~：兩邊各兩個 `~`

**無序與有序列表：**

```markdown
- 來杯咖啡
- 看點程式碼
- 寫點筆記

1. 第一步先安裝
2. 第二步設定
3. 第三步別忘了踩坑筆記
```

**引用 — 適合放名言或自己的吐槽：**

> 寫程式第一原則：先讓它動起來，再讓它變漂亮。

**行內程式碼與程式碼區塊：** 行內用反引號包住，例如 `console.log("hello")`。塊狀的：

```javascript
const greeting = '你好，世界';
console.log(greeting);
```

**表格：**

| 方案             | 成本         | 適合               |
| ---------------- | ------------ | ------------------ |
| VPS              | 每個月幾百塊 | 想要完全掌控       |
| Cloudflare Pages | $0           | 個人博客，像我這樣 |

**連結與圖片：**

```markdown
[連結文字](https://example.com/)
![替代文字](/covers/hello-world.svg)
```

**分隔線**：三個以上的 `-` 或 `*`。

最後一個小知識：這個博客渲染時**單換行也會直接變成換行**（`breaks` 開啟），所以寫作時不用空一行，排版也能保持；程式碼區塊和大部分語法一樣有淺色／深色兩種樣式，會自動跟著主題變。

差不多就是這些。慣例收尾：你好，世界。
